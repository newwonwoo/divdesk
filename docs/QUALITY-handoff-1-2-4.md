# 품질확인서 — HANDOFF 3절 1·2·4순위 + 스코어 잔여 결함

작성 2026-08-05 · 대상 `collector/sources/yahoo.py` · `collector/store.py` ·
`db/migrate.py` · `engine/score.py` · `scripts/diagnose_prices.py` · `Makefile`

## 1. 가장 중요한 발견

**HANDOFF 1순위의 "코드 쪽 할 일은 끝났다"(2026-08-03 정정)는 틀렸다.**

마이그레이션으로 `open`·`low` 컬럼을 만들고 재수집해도 값은 안 들어왔을 것이다.
`yahoo.fetch_history` 가 `(날짜, 종가, 수정종가)` **3튜플만** 돌려주고,
`store.pad()` 가 이를 5개로 늘리며 시가·저가를 **항상 `None`** 으로 채웠기
때문이다. 배당락 회복력 10점은 그대로 영구히 중립이었을 것이다.

야후 chart 응답에는 `open`·`low` 가 처음부터 들어 있었다. `res["indicators"]
["quote"][0]` 에서 `close` 만 꺼내 쓰고 나머지를 버리고 있었을 뿐이라,
추가 요청 없이 그대로 읽도록 바꿨다.

곁들여 **`python -m db.migrate` 에 진입점이 없었다.** `run(conn)` 만 있고
`__main__` 블록이 없어 HANDOFF 가 안내하던 이 명령은 **아무 일도 하지 않고
조용히 끝났다.** 돌렸다고 믿게 만드는 실패라 우선 고쳤다.

## 3. 한 일

### 1순위 — 시가·저가가 실제로 흐르게

- `yahoo.fetch_history` 반환을 `(날짜, 종가, 수정종가, 시가, 저가)` 5튜플로.
  배열이 없거나 짧아도 `None` 으로 두는 헬퍼를 써서 한 종목 결측이 수집 전체를
  죽이지 않게 했다.
- `db/migrate.py` 에 `main()` + `__main__`. `Makefile` 에 `migrate` 타깃.
- `store.upsert_history` 가 `with_open`(시가 있는 행 수)을 반환해 수집 로그에서
  채워졌는지 바로 보인다.

### 2순위 — 재고 나서 고친다

- `scripts/diagnose_prices.py` 신설. **SELECT 만 한다.** 종목별 행 수·최근 1년·
  주말 행·`외톨이`(같은 시장 대다수에 없는 평일)·시가 없음·ma200 없음을 찍는다.
  같은 시장은 같은 날 쉬므로 소수 종목에만 있는 평일은 잘못 들어온 날짜다.
- `store.upsert_history` 가 **주말 행을 버린다.** 주말은 공휴일 표 없이도 아는
  구조적 사실이라(CLAUDE.md: 공휴일 표를 만들지 마라) 막아도 안전하다.
  조용히 버리지 않고 `weekend_dropped` 로 개수를 보고한다.
  들어오면 200일선·52주 창이 밀리고, `engine/calendar.py` 가 거래일을 수집된
  날짜에서 도출하므로 휴장일 판정까지 함께 틀어진다.

### 4순위 — 코드 확인

`upsert_history` 가 날짜별 `indicators` 를 만들어 행마다 저장하고,
`ON CONFLICT ... SET ma200=EXCLUDED.ma200` 이라 재수집이 과거 행을 덮어쓴다.
1순위의 `make collect` 한 번에 함께 풀린다. 별도 작업 없음.

### 세션분 — 스코어 잔여 결함

- `confidence` 를 두 번 계산하던 것을 정본 하나로. 예전에는 등급 판정이
  `100 - 결측×16`, 화면 표시가 `(1 - 결측/6)×100` 이라 어긋났다(결측 3개면
  52 vs 50). 결론이 갈리는 구간이 없어 증상은 없었다.
- `ScoreInput.fx_exposed` 3회·`ScoreResult.confidence` 2회 선언을 하나로.
  `fx_exposed` 는 파이썬이 마지막 선언만 남겨 실제 기본값이 `True` 였고,
  앞 선언을 전제로 쓴 `is not None` 분기는 도달할 수 없었다. **기본값은 그대로
  두고** 타입만 `bool | None` 으로 합쳐, `None` 을 명시하면 상장 통화로 되짚는
  분기가 다시 살아나게 했다.
