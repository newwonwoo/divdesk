# DESIGN — DivDesk 설계서

갱신 2026-08-02 · 근거 문서: `QUALITY-백테스트.md`, `QUALITY-타점재설계.md`

이 문서는 **무엇을 왜 그렇게 만들었는가**를 담는다. 특히 5절은 검증으로
걸러낸 설계라 되돌리면 안 된다.

---

## 1. 이 앱이 답하는 두 질문

```
① 이 상품이 살 만한가   →  품질 축 (안정성)
② 지금이 살 때인가       →  타점 축 (얼마나 싸게 사는가)
```

두 축을 분리한 이유는, 하나로 합치면 **좋은 상품이 비쌀 때도 높은 점수가 나와**
판단이 흐려지기 때문이다.

## 2. 시스템 구조

```
사용자 ── Vercel(React/Vite) ── vercel.json 프록시 ──> EC2 FastAPI
                                                         │
                        cron(매일 6:30 토스 / 7:00 시세) ─┤
                                                         │
                        engine/*  ←── engine/asof.py ────┤
                                                         │
                                                    PostgreSQL
```

핵심은 **`engine/asof.py` 하나로 채점 입력 조립을 모았다**는 것이다.
프로덕션(`/scores/recompute`)과 백테스트가 같은 함수를 쓴다. 두 벌로 만들면
"프로덕션과 다른 채점기를 검증"하는 셈이 되기 때문이다.

`asof.py` 는 지표를 **저장 컬럼에서 읽지 않고 종가 시계열에서 그 시점 창으로
다시 계산**한다. 저장 `ma200` 이 마지막 날짜치만 있어 과거 재구성이 불가능했고,
매일 backfill 도 되지 않았기 때문이다. 부수적으로 **200일선 기울기가 상시
중립이던 버그**도 이걸로 해소됐다.

### 데이터 모델 (요지)

| 테이블 | 역할 | 주의 |
|---|---|---|
| `etf_master` | 종목 성격 분류 | 주가·배당률 넣지 마라. 수집기가 채운다 |
| `etf_price_daily` | 일별 OHLC·수정종가·지표 | **`open`·`low` 컬럼이 아직 없다** (HANDOFF 1순위) |
| `dividend_history` | 배당락일별 분배금 | `is_estimate=false` 만 계산에 쓴다 |
| `fx_rate` | USD/KRW | 2021-08 부터뿐 |
| `purchase` | 매수기록 (토스 동기화) | `is_opening_balance` 는 환차익 계산에서 제외 |
| `score_snapshot` | 일자별 점수 | `facts` JSON 에 항목표·품질·타점·신뢰도 |
| `tax_param` | 세율 | **코드에 세율 숫자를 쓰지 마라** |

`score_snapshot.facts` 는 **두 형식이 섞여 있다.** 옛 형식은 배열
`[[항목,값,부연,획득,만점], ...]`, 새 형식은 객체 `{facts, quality, timing,
excluded, confidence}`. 프론트는 둘 다 받도록 돼 있다. 재계산을 돌리면 새 형식이 된다.

## 3. 채점 설계

```
배당률 30 (수준 18 + 이력 위치 12)
가격 위치 20        ← 타점
분배금 성장 15
위험조정 수익 15
환율 10             ← 타점
배당락 회복력 10

종합 = 품질 × 0.75 + 타점 × 0.25
품질 50점 미만 → 제외 (나쁜 상품을 싸다고 사면 안 된다)
데이터 신뢰도 50% 미만 → 판단보류
```

배당률의 **이력 위치 12점만 원인에 따라 두 축으로 나뉜다.** 배당률이 오른 이유가
배당 성장이면 품질로, 주가 하락이면 타점으로 간다. 안 나누면 배당 성장 종목을
"지금 싸다"고 잘못 읽는다.

### 가격 위치 20점 — 낙폭 하나만 본다

```
점수 = 20 × min( 절대기준, 자기이력기준 )
  절대기준     clip(-낙폭 / 0.10)        -10% 면 만점
  자기이력기준  과거 낙폭 분포에서의 위치   역대 최악이면 1.0
```

**둘 중 낮은 쪽**을 쓴다. 절대 기준만 보면 -10% 상한에 자주 포화돼(짧은 이력
관측의 33%가 만점) 변별력을 잃고, 자기 이력만 보면 아직 위기를 겪지 않은 종목이
평범한 조정에 만점을 받는다. 서로의 실패를 막는 구조다.

화면 표기는 백분율이 아니라 **순위**다 — `과거 낙폭 100건 중 15번째로 큼`.
"상위 85%"는 심한 건지 평범한 건지 즉시 읽히지 않는다.

### 위험조정 수익 15점

`min(Sortino, Calmar) × 0.7 + Sharpe × 0.3`, 3년.
**최솟값을 쓰는 게 핵심이다.** 평균이면 한 지표가 나빠도 다른 게 덮는다.
JEPQ 는 Sortino 상위권인데 Calmar 하위권이었다 — "평상시엔 안정적인데 한 번 크게
빠지는" 커버드콜 특성이 평균에서는 가려지고 최솟값에서는 드러난다.

### 환율 10점

**상장 통화가 아니라 기초자산 통화**를 본다. TIGER 미국배당다우존스는 원화로
사지만 기초자산이 미국이라 환율에 그대로 노출된다. 3년 밴드 위치.

## 4. 백테스트 — 무엇을 어떻게 검증했나

`scripts/backtest.py` (전체), `bt_price.py` (가격만), `bt_decomp.py` (요소 분해),
`bt_variants.py` (낙폭 정규화 비교), `bt_gc.py` (골든크로스), `bt_blend.py` (혼합).

방법: 매월 말 시점에 그 시점 데이터만으로 채점 → 이후 3·6·12개월 총수익 기록 →
점수 구간별 비교. look-ahead 는 `scripts/test_asof.py` 로 단위 검증한다
(미래를 잘라낸 패널과 결과가 일치하는지).

**해석의 세 가지 원칙**

1. **동일종목 내 비교가 가장 깨끗하다.** 종목을 고정하면 품질 교란이 사라져
   타점의 순수 예측력만 남는다. 횡단면 분위는 "점수 높은 종목이 더 좋았다"를
   보여줄 뿐 "지금이 살 때다"를 맞힌 게 아니다.
2. **종목 수는 표본이 아니다.** 29종이 모두 같은 시장의 같은 급락(2018 말·
   2020-03·2022)을 공유하므로 "28/29종 일관"은 독립 관측 28건이 아니라 사실상
   **급락 사건 3~4건**에 대한 관측이다.
3. **12개월 창이 겹친다.** 유효 독립표본은 표시된 n 보다 훨씬 적다. 유의성을
   주장하지 말고 방향·단조성·기간 일관성만 읽어라.

## 5. 검증으로 걸러낸 설계 — 되돌리지 마라

### 5-1. 200일선 기울기 (8점) → 제거, 뒤집기도 금지

| 지표 | 값 |
|---|---|
| 상관 | -0.257 |
| 동일종목차 | -11.8% |
| 양(+) 종목 | **0/23** |
| ~2021 / 2022~ | -0.409 / +0.030 |

23종 **전부** 음(-)이다. 이 연구에서 가장 일관된 항목이었다. 어느 기간에서도
양(+)인 적이 없어 8점 배점의 근거가 없다.

**그런데 뒤집는 것도 부당하다.** 최근 기간 상관이 0 이라 반대편에 걸 근거가 없고,
뒤집으면 "하락 추세일수록 가점"이 되어 배당 삭감이나 섹터 붕괴처럼 **구조적으로
무너지는 종목에 최고점**을 준다. 이번 표본에서 하락이 다 회복된 건 시장 전체
급락이었기 때문이지 개별 종목이 망가진 경우가 아니었다.

> 제거는 중립이고 뒤집기는 반대편 베팅이다. 증거가 급락 서너 번뿐일 때는
> 베팅하지 않는 쪽이 맞다.

원래 의도(하락 추세 주의)는 **경고 문구로 남겨** 지켰다.

### 5-2. 골든크로스 MA50/200 → 검증 후 제외

| 신호 | 상관 | 동일종목차 | 양(+) |
|---|---|---|---|
| GC 상태 | -0.228 | -3.3% | 8/23 |
| GC 이격 | -0.239 | -8.8% | **0/23** |
| GC 최근돌파 | -0.002 | +1.0% | 9/23 |

핵심은 조합이었다. **낙폭이 큰 구간에서 골든크로스가 있는 쪽 +12.5%,
없는 쪽 +16.1% (차 -3.6%p).** 반등을 확인하고 사면 이미 늦는다.
조합 점수도 낙폭 단독 +0.342 → 낙폭×GC가점 +0.307 로 **떨어졌다.**

GC 이격의 0/23 은 200일선 기울기와 같은 수치다 — 이름만 다를 뿐 둘 다
"지금 상승 추세인가"를 재고 있었다.

### 5-3. 20일 과열 감점 (6점) → 제거

상관 -0.045, 5분위가 U자(양극단이 좋고 중간이 나쁨). **비단조라 선형 배점으로
담을 수 없다.** 억지로 담으면 중간 구간에 틀린 확신을 준다.

### 5-4. 왜 합계가 예측력이 없었나

가격 위치 20점은 **성격이 반대인 신호를 겹쳐** 놓고 있었다.

```
기울기 8점  추세추종  방향 반대 (-0.238)  ─┐
낙폭   6점  역추세    방향 맞음 (+0.310)  ─┼→ 합계 -0.051
20일   6점  역추세    거의 무 (-0.008)   ─┘
```

각 항목은 따로 보면 ±13% 씩 힘이 있는데 합쳐 놓으니 서로를 지웠다. 게다가
**부호가 틀린 쪽에 가중치가 더 컸다**(8 vs 6). 신호가 없어서가 아니라 반대로
겹쳐 놓아서였다.

### 5-5. 타점 비중 60% → 25%

타점을 구성하는 두 항목의 상태:

- **가격 위치** — 검증 실패. 낙폭만 방향이 일관되나 **2022년 이후 상관이 0
  부근으로 무너진다**(+0.035). 전체 +0.31 은 사실상 2020년 급락과 V자 회복이
  만든 값이다.
- **환율** — 검증 불가. fx 이력이 2021-08 부터라 3년 밴드조차 실질 독립 관측이
  두어 개다. 게다가 해당 기간 원화가 일관되게 약세여서 예측이 아니라 추세를
  되읽은 값에 가깝다.

검증되지 않은 축에 40%를 걸 수 없다. 0 으로 두지 않은 이유는 "지금이 살 때인가"가
이 앱의 두 질문 중 하나이기 때문이다.

## 6. 남은 정직한 한계

- **모든 가격 기반 타점 신호가 2021년 이전에만 강했다.** 낙폭도 기울기도
  2022년 이후 무너진다. 사실상 **2020년 급락·회복 사건 하나**에서 신호가 나온다.
- 2017~2026 은 대형주 강세와 급락 후 빠른 V자 반등이 반복된 특이 구간이다.
  다음에도 그러리라는 보장은 없다.
- 이 시기 배당 ETF 는 **지수에 통째로 뒤졌다** — 벤치(SPY·VOO·QQQ) 12개월 평균
  +15.7%, 후보의 어느 타점 분위보다 높다.
- 국내 종목은 일봉이 2022~23년부터라 결론에 거의 기여하지 못했다.

따라서 결론은 **"이 점수 체계가 이 기간에 작동하지 않았다"** 이며,
"타이밍 판단 자체가 불가능하다"는 아니다.
