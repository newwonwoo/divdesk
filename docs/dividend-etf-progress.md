## 앱 개요

배당 ETF만 다루는 "매수 의사결정 도구". 얼마를 사면 세후 월배당이 얼마인지(정방향),
목표 월배당을 받으려면 얼마를 사야 하는지(역방향), 그리고 지금이 살 타점인지(점수화)를
한 화면에서 판단하고, 매수기록·배당예상일지·추천알람까지 이어지는 구조.

## 핵심 계산 엔진 3개

### 엔진 1. 정방향 — "3,000만원 넣으면 월 얼마?"
```
연 세전배당 = Σ(종목별 투자금 ÷ 주가 × 최근4회합산DPS)
월 세전배당 = 연 세전배당 ÷ 12      (실제 입금은 월별 편차 → 캘린더에서 표시)
세후 = 세전 × (1 - 실효세율)
원화 = × 적용환율
```
※ 분기배당 종목만 담으면 "월평균"과 "실제 월입금"이 다르다는 경고를 반드시 노출.

### 엔진 2. 역방향 — "월 100만원 받으려면?"
```
필요 연배당(세전) = 목표월배당 × 12 ÷ (1 - 실효세율) ÷ 환율
필요 투자금 = 필요 연배당 ÷ 포트폴리오 가중배당률
→ 종목별 주수(정수 내림) + 부족분 재계산 루프
```
- 배분 모드: ① 균등 ② 배당률 최대 ③ 안정성 우선 ④ 사용자 지정 비중
- 출력: 필요 총액 / 종목별 주수 / 예상 월별 입금 그래프 / 세금 / 목표 달성률

### 엔진 3. 매수타점 스코어 (0~100)
| 항목 | 배점 | 계산 |
|---|---|---|
| 배당률 백분위 | 30 | 현재 배당률이 자기 5년 밴드에서 상위 몇 %인지 (높을수록 싸다) |
| 가격 위치 | 20 | 200일선 이격도 + 52주 밴드 위치 |
| 분배금 건강도 | 20 | 최근 12개월 DPS vs 전년, 감액·중단 이력, 커버드콜은 ROC 비중 |
| 총수익 정합성 | 10 | 최근 1년 분배율 vs 총수익률 (분배가 원금 깎는지) |
| 환율 위치 | 10 | USD/KRW 3년 백분위 (원화투자자 관점 페널티) |
| 배당락 타이밍 | 10 | ex-date 근접 시 페널티(고점매수), 직후 보너스 |

→ 85+ **적극매수** / 70~84 **매수** / 55~69 **분할·관망** / 55↓ **보류**
→ 근거 문장 자동 생성 ("배당률 4.2%는 5년 상위 12% 구간, 200일선 -6.3%, 단 3일 후 배당락")

**커버드콜 경고 규칙(필수)**: 배당률 8% 이상 종목은 스코어와 별개로
"분배금 ≠ 수익. 총수익 기준 판단 필요" 배지를 항상 붙인다.

## 세금 모델 (2026 기준, 근거 명시형)

3가지 계좌 모드로 분기 처리:

**모드 A. 일반계좌 / 미국 상장 ETF (JEPI, SCHD 등 직접투자)**
- 미국에서 배당 15% 원천징수. 한국 배당소득세율(14%)보다 높아 통상 추가 납부 없음.
- 지방소득세 1.4%분은 외국납부세액공제 처리에 따라 달라짐 → 실효 15%로 계산, 주석 표기.
- 연 금융소득(이자+배당) 2,000만원 초과 시 금융소득종합과세 → 근로소득 합산 누진(6.6~49.5%).
- 매매차익은 별건: 양도소득세 22%, 연 250만원 기본공제, 분리과세(종합과세 미포함).
- 주의: 국내에서 원천징수되지 않은 국외금융소득은 2,000만원 이하라도 신고대상이 될 수 있음.

**모드 B. 일반계좌 / 국내 상장 해외배당 ETF (TIGER 미국배당다우존스 등)**
- 분배금 15.4% 원천징수(소득세 14% + 지방 1.4%).
- 매매차익도 배당소득으로 15.4% 과세(보유기간 과표기준가 상승분 vs 실제차익 중 적은 금액).
- 2025년부터 외국납부세액 '선환급' 방식 폐지 → 과거보다 실효세율 상승. 계산기에 반영.
- 분배금+매매차익 합산 2,000만원 초과 시 종합과세.

**모드 C. 절세계좌 (ISA / 연금저축 / IRP) — 국내상장만 가능**
- 분배금 즉시 과세 없음 → 과세이연, 연금수령 시 저율과세(3.3~5.5%) 또는 ISA 비과세·9.9% 분리과세.
- 미국 상장 ETF는 편입 불가 → 국내상장 유사종목 매핑 테이블로 대안 제시.

**금융소득 워치독**: 연초부터 누적 세전 금융소득을 실시간 추적,
2,000만원의 80%(1,600만) 도달 시 경고 배너 + 절세계좌 이전 제안.
※ 2026년 배당소득 분리과세 개정 논의가 진행 중 → 세율 상수는 DB 테이블로 분리해 즉시 교체 가능하게 설계.

## 배당예상일지 (자동 캘린더)

1. 종목별 과거 4~8회 ex-date/pay-date 패턴을 규칙으로 추출
   (예: JEPQ = 매월 초 ex, +2~3영업일 pay / SCHD = 3·6·9·12월 하순)
2. 운용사 공식 배당스케줄(Vanguard DIVDAT 등) 있으면 우선 적용, 없으면 패턴 추정
3. 예상 DPS = 최근 4회 평균 × 성장추세 보정(선형), 커버드콜은 변동폭 밴드로 표시
4. 출력: 월별 캘린더 + 12개월 예상 입금 그래프(세전/세후/원화) + 확정/추정 배지 구분
5. 배당락 D-3 알림, 입금 예정일 알림

## 데이터 신뢰 원칙 (사용자 원칙 반영)

- 배당률·DPS·주가는 절대 하드코딩 금지. 전부 수집 후 DB 저장, 화면에 `기준일` 표기.

   - MVP에서는 "다음 배당락일 D-n"만 스코어에 쓰고, 전체 캘린더 화면은 2차.

4. **절세계좌 비교 모드 추가**: 미국상장 종목 조회 시 국내상장 대체종목(`kr_alt_ticker`)을 매핑해
   "일반계좌 미국상장 vs 절세계좌 국내상장" 세후 수령액을 나란히 비교. 절세계좌는 국내상장만 편입 가능.

5. **국내 데이터 소스 추가** (yfinance는 국내 ETF 분배금 커버리지가 약함)
